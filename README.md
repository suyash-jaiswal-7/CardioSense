## 📌 Overview

CardioSense is a machine learning project built to explore how classification algorithms can be applied to a heart disease dataset.

The project covers the complete workflow, from data preprocessing and feature encoding to model comparison, evaluation, serialization, and deployment through Streamlit Community Cloud.

### ✨ Key Features

- 🩺 **Interactive predictions:** Enter health-related feature values through a web interface.
- 🤖 **Machine learning classification:** Uses a trained K-Nearest Neighbors (KNN) model.
- 📊 **Model comparison:** Evaluates multiple classification algorithms using test-set metrics.
- ⚙️ **Preprocessing pipeline:** Uses one-hot encoding and feature standardization during model development.
- 💾 **Saved artifacts:** Loads the trained model, scaler, and feature-column list.
- 🌐 **Live deployment:** Accessible through Streamlit Community Cloud.
- 🎨 **User-friendly interface:** Presents predictions using readable labels.

## 🧠 Machine Learning Workflow

The project follows these stages:

1. **Data preparation:** Load the heart disease dataset and inspect its features.
2. **Feature encoding:** Apply one-hot encoding to categorical variables using `pandas.get_dummies()` with `drop_first=True`.
3. **Feature-target separation:** Separate the input features (`X`) from the target (`y`).
4. **Train-test split:** Use an 80:20 split with stratification and `random_state=42`.
5. **Feature scaling:** Fit `StandardScaler` on the training data and transform the training and test sets.
6. **Model comparison:** Train and evaluate multiple classification algorithms.
7. **Model selection:** Select KNN based on the observed test-set performance.
8. **Artifact serialization:** Save the model, fitted scaler, and feature-column names using Joblib.
9. **Deployment:** Load the saved artifacts in the Streamlit application.

## 📊 Model Comparison

The following results were observed during model evaluation on the held-out test set.

| Model | Accuracy | F1 Score |
|---|---:|---:|
| Logistic Regression | 87.50% | 0.8878 |
| **K-Nearest Neighbors (KNN)** | **88.59%** | **0.8966** |
| Gaussian Naive Bayes | 86.96% | 0.8788 |
| Decision Tree | 73.91% | 0.7500 |
| Support Vector Machine (RBF) | 86.41% | 0.8804 |

**Selected model: K-Nearest Neighbors (KNN)**

KNN achieved the highest accuracy and F1 score among the evaluated models in this experiment.

> These figures describe performance on this particular test split. They do not establish clinical reliability or guarantee performance on unseen populations.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/suyash-jaiswal-7/CardioSense.git
cd CardioSense
```

### 2. Create and activate a virtual environment

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

## 📦 Model Artifacts

The application uses the following saved files:

- `KNN_heart.pkl` — trained KNN classifier.
- `scaler.pkl` — fitted feature scaler.
- `columns.pkl` — ordered feature names used during training.

These artifacts help the application apply the same fitted preprocessing and feature ordering used by the trained model.

**Important:** Only load trusted `.pkl` files. Pickle-based files can execute code when deserialized.
